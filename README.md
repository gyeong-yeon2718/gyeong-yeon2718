전력회로 설계·계측부터 차량·로봇 제어와 시스템 통합까지 경험한 **한양대학교 전기공학 전공 박경연**입니다.
소자와 제어기의 동작을 해석하고, 시뮬레이션·실측·현장 로그로 설계 판단을 확인하는 데 관심이 있습니다.

### 주로 다룬 영역

| 회로·전력전자 | 검증·해석 | 제어·시스템 통합 |
| :--- | :--- | :--- |
| 공진 회로 · 소자 선정 · Type-III 보상기 | 계측 · 과도응답 · 요구사항과 시험 연결 | 센서·제어·통신 연동 · 로그 분석 |
| PSIM · PSpice · MATLAB | 오실로스코프 · Simulink · Jira | ROS · ROS 2 · Arduino |
